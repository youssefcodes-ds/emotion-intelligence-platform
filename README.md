# Customer Sentiment & Emotion Intelligence Platform

An end-to-end NLP platform that classifies customer messages into six emotions,
compares classical NLP against deep learning, and exposes results through a
Streamlit application.

## Problem

Support teams receive more unstructured text than they can read, and a binary
positive/negative label is too coarse to route or prioritise a message. This
system classifies each message into one of six emotions and aggregates the
results into support intelligence.

Emotion labels are **not** clinical or mental-health assessments.

## Dataset

[`dair-ai/emotion`](https://huggingface.co/datasets/dair-ai/emotion), `split`
configuration: 16,000 train / 2,000 validation / 2,000 test, six classes
(`sadness, joy, love, anger, fear, surprise`).

Raw data is not committed; it is regenerated by the pipeline. The processed
splits **are** committed so every member trains on identical rows.

## Reproducing the pipeline

```bash
pip install -r requirements.txt

python -m src.data.ingest           # download raw          -> data/raw/
python -m src.data.build            # clean + split         -> data/processed/
python -m src.data.load_sql         # build warehouse       -> data/emotion.db
python -m src.data.run_queries      # run 14 queries        -> reports/sql_results/
python -m src.data.eda              # figures + EDA report  -> reports/
python -m src.data.data_dictionary  # data dictionary       -> reports/
pytest -q                           # unit tests
```
